# 风险登记

- R-01｜数据外泄：MCP 客户端收到的内容可能送到上游模型；本机 stdio 并不阻断外部模型。控制：按授权范围查询，研发与审查只用合成数据。状态：设计已确认，实现未审查。
- R-02｜不完整数据误报为空：消息缺字段、来源路径变化、损坏行或解压不全。控制：逐源状态、partial 和定位证据；DSH 多帧做轻量检查。状态：未验证。
- R-03｜误写与越界：原数据库、Windows junction/符号链接、检查后打开竞态。控制：只读连接与路径边界；Cursor 专门审查。状态：未验证。
- R-04｜上游版权：MIT 代码复用须保留许可，无许可证的项目不复制。状态：待审查。
- R-05｜质量：本轮按用户要求以 Review 为主，轻量测试不覆盖所有来源和安全分支。状态：未验证，不能宣称全面验收通过。
